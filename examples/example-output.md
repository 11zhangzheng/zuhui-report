# 组会汇报 - 基于图神经网络的分子性质预测

汇报人：张同学
汇报时间：2026-10-13

## 一、本周工作进展

- 完成文献调研：梳理 2023–2025 年 GNN 分子性质预测的 5 篇代表性工作，明确以 **MPNN + 注意力池化** 作为基线路线。
- 完成数据预处理管线：从 ChEMBL 抽取 12,480 条化合物记录，统一 SMILES 标准化与 8:1:1 数据划分，随机种子固定为 42。
- 完成基线模型代码：实现 3 层 message passing + 全局注意力池化的 GNN，打通训练 / 验证 / 测试全流程（`train.py`、`model/gnn.py`）。
- 完成首个可复现实验：在 ESOL 数据集上完成 5 折交叉验证。

## 二、实验/研究结果

**有效结果**
- 基线模型在测试集上 RMSE = 0.71，优于随机森林基线（RMSE = 0.89）。
- 学习率 1e-3 + AdamW + cosine 退火组合下收敛稳定，30 epoch 内验证损失单调下降。

**失败尝试（如实记录）**
- 尝试加入 2D 骨架特征时，验证集 RMSE 反升至 0.83，怀疑是特征维度膨胀导致过拟合，暂时搁置。
- 一次性加大到 5 层 message passing 后出现明显过平滑（over-smoothing），深层节点表示几乎无法区分，计划改用残差连接缓解【待验证】。

## 三、现存难点与踩坑

- **数据泄漏风险**：当前划分按行随机拆分，同一分子的不同活性记录可能跨集合，指标可能偏乐观。
  - 已尝试：检查重复 SMILES，发现约 3% 重复；改用骨架拆分（scaffold split）的具体实现尚未确定【待验证】。
- **显存瓶颈**：batch size 超过 64 时出现 OOM（RTX 3090, 24GB）。
  - 已尝试：梯度累积（effective batch = 128）可跑通，但训练时间增加约 40%。

## 四、下一步工作计划
